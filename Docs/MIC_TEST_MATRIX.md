# Microphone test matrix

Each row is a device/environment combination. Fill in **date** and **result** after every test; an empty row means untested. The goal: the game is never judged with an uncalibrated microphone.

**The team is on Linux, so Linux is the platform being tested** — the editor on the lead's machine is the reference rig and the Linux player build is the delivery target. Nothing here has ever been measured on Windows; if a Windows build is made later it gets its own rows.

**Schedule:** rows 1–2, 6–9 and 13–14, 17 are week 2 tests (`MicrophoneEchoSource` + the gate land then). Rows 3–5 and 10–12 need the calibration page, the Options persistence and the pause/quit handling, which are week 3.
